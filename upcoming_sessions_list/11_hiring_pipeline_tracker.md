# Session 11: Hiring Pipeline Tracker

**Manager problem:** Open positions stall silently — a candidate's gone quiet, an interview loop is incomplete — and it's only noticed when the start date is already at risk.

**Channels:** Outlook mail (recruiter/candidate threads), Outlook Calendar (interview slots), Teams (interviewer feedback), Excel `hiring.xlsx` (open positions, target start dates).

**Magic:** Track each requisition's pipeline stage against `hiring.xlsx`, catch the trend of stages sitting idle too long, and summarize hiring health per team. Next steps ("chase feedback from interviewer 2", "re-engage candidate") get tracked to closure.

**Data:** Separate dataset — recruiter emails, interview calendar entries, and Teams feedback threads for a handful of open roles at different pipeline stages.

**Outcome:** A hiring pulse that catches stalled requisitions before the target start date slips.
