# Session 7: RAID Log Automation

**Manager problem:** Risks, assumptions, issues, and dependencies get mentioned in passing across meetings and chat, but the RAID log is only ever updated when someone remembers.

**Channels:** Outlook mail (meeting-minute emails), Teams/Slack (project channels), Excel `projects.xlsx` (project plan, owners).

**Magic:** Continuously scan for risk/issue language across channels, add new entries to a living RAID log, and re-surface old ones that haven't moved. Catches the trend of a risk mentioned repeatedly without an owner acting on it.

**Data:** Separate dataset — meeting and chat snippets seeded with risks/issues at varying urgency, some resolved, some ignored.

**Outcome:** A RAID log that builds itself from normal project chatter instead of a dedicated update ritual.
