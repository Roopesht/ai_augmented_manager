# Session 2: Client Status Report Roll-up

**Manager problem:** Manually reading status emails, Teams/Slack channel chatter, and client meeting notes, then stitching them into one coherent client report.

**Channels:** Outlook mail (status emails), Teams/Slack (project channel updates), Outlook Calendar (client meeting cadence), Excel `projects.xlsx` (expected outcomes/milestones).

**Magic:** Reconcile this week's activity against the expected-outcomes sheet, catch the trend (confidence dropping, cadence slipping vs last 3 weeks), auto-summarize the initiative, and consolidate next steps mentioned anywhere across channels — then, next week, check off which of those next steps actually happened.

**Data:** Separate dataset — status emails, Teams messages, and calendar entries generated together for the same project, reconciled against `projects.xlsx`.

**Outcome:** A trustworthy weekly client report plus a self-updating "did we do what we said" trail.
